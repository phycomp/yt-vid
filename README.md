# yt-vid

YouTube video production skill — content planning, script writing (two-column AV), storyboard/shot list, batch shooting, SEO, 10-minute video structure, production workflow, and publishing checklist.

## What it does

- Content planning (pillars, 12-week calendar, SEO titles/tags)
- Script writing (two-column AV, hooks, CTAs, runtime math)
- Storyboard (decision document, shot table, AI previz)
- Shot list & batch shooting (by-setup grouping)
- YouTube SEO (title, tags, description, thumbnail)
- Production workflow (weekly Mon-Fri schedule)
- Publishing checklist & KPIs

## Install

```bash
npx skills add phycomp/yt-vid@yt-vid -g -y
```

## Usage

Trigger phrases: "video production", "video script", "storyboard", "shot list", "YouTube SEO", "content planning", "publishing workflow", "10-minute video".
